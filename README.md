# 征地统计助手

一个 Excel 加载项（.xlam），把征地导出的原始明细（竖表）一键整理成两份正式表：

- **分户面积表** —— 一户一行，横向铺开各地类面积
- **村组统计表** —— 一个村组一行，横向汇总

> 仓库里的 `示例-征地项目统计表模板.xlsx` 是一份**脱敏示例**（姓名、村名都是假的），可以先打开它看看三张表长什么样、明细数据怎么摆。

## 怎么用

1. 下载 `征地统计助手 安装程序.exe`，双击运行
2. 点「**安装到 Excel**」，看到「安装完成」即可
3. 打开你的统计表工作簿，确认里面有三张表（名字要一模一样）：
   - 原始导出数据
   - 分户面积表
   - 村组统计表
4. 把导出的明细粘到「原始导出数据」，一共五列：

   | 图斑编号 | 权属（村组名） | 户主 | 面积 | 地类代码 |
   |---|---|---|---|---|

5. 点顶部「**征地助手**」选项卡 →「一键生成」，两张表就自动填好了

## 装好了却看不到选项卡？

点安装程序里的「**修复**」按钮。它会做五件事，都只针对「征地统计助手」：

1. 重新放好加载项文件，去掉「从网上下载」的锁定
2. 清掉 Excel 禁用名单里属于它的记录
3. 检查它在 Excel 启动项里登记了没有，没登记就补上
4. 清掉 XLSTART 里多出来的同名副本
5. 检查宏安全设置（**但不会更改**）

> 修之前先把 Excel 完全关掉（任务栏看不到、任务管理器里也没有 EXCEL.EXE 才算关干净）。

## 卸载

点「**卸载**」即可。加载项文件、启动登记、禁用名单、XLSTART 副本一并清掉。

## 安全说明

- 安装只写当前用户的 Excel 启动项（`HKCU\...\Excel\Options` 的 `OPEN` 值），**不需要管理员权限**
- 「修复」只认「征地统计助手」这一个加载项
- 宏安全设置只读不写；要改得你自己去 Excel 选项里改
- 文件带着「从网上下载」锁定的话，安装时自动解锁
